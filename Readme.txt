管理バーの不要な項目を強制検知して非表示にし、サイト名を自動で省略して表示を最適化する軽量プラグインです。

== Description ==

My Admin Bar Customizer は、WordPressの管理バー（ツールバー）を整理し、作業画面をスッキリさせるためのカスタマイズプラグインです。

主な特徴：

・管理バー項目の自動検知（標準メニューおよびサードパーティ製プラグインに対応）
・チェックボックスによる直感的な非表示設定（引き算方式）
・長すぎるサイト名を自動で省略表示（15文字制限、末尾「...」付与）
・非表示にした項目もリストに保持し、いつでも復元可能
・「検知済みリスト」のリセット機能により、プラグイン変更時も再スキャンが可能
・パフォーマンス最適化（軽量なフック処理と最小限のDBアクセス）

== Installation ==

1. プラグインフォルダを配置します
   `wp-content/plugins/my-admin-bar-customizer/`

2. 以下のファイル構成を確認してください
   - `my-admin-bar-customizer.php`

3. WordPress管理画面からプラグインを有効化します

4. 「設定 > 管理バー設定」から非表示にしたい項目を選択し、「変更を保存」をクリックしてください

== Usage ==

プラグインを有効化すると、現在認識されている管理バーの項目がリストアップされます。

・非表示にしたい項目のチェックボックスをオンにして保存してください。
・新しいプラグインを導入して項目が増えた場合、一度サイトのフロントページ（公開側）を表示することで、自動的にリストへ追加されます。
・サイト名が15文字を超える場合は、自動的に省略して表示されます。

== Settings ==

「設定 > 管理バー設定」より以下を設定可能です：

・非表示にするメニューの選択：検知された親メニューの一覧から選択
・検知済みリストをリセット：DBに保存されたメニュー構造を初期化し、現在の環境で再スキャンします

== Notes ==

・このプラグインは「引き算方式」を採用しているため、チェックを入れていない項目が勝手に消えることはありません。
・サイト名の省略ロジックは、管理バー上の表示のみを変更し、実際のサイト名設定には影響を与えません。
・特定のプラグイン（WP Fastest CacheやUpdraftPlusなど）の項目がリストに出ない場合は、一度それらの項目が表示されている画面を表示してください。
