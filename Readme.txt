== Description ==

My Admin Bar Customizer は、WordPressの管理バー（ツールバー）を整理し、作業画面をスッキリさせるための実用的なプラグインです。

動的なメニュー保存時に発生しがちな「設定の消失」を独自の先行保存ロジックで解決しており、サーバー環境を選ばず安定して動作します。

主な特徴：

* **高度な項目検知**: 標準メニューに加え、外部プラグイン（キャッシュプラグインやSEOツール等）が追加した項目も自動でリスト化します。
* **データ消失防止ロジック**: 独自の保存プロセスにより、保存時に設定一覧が消えるトラブルを完全に防止。
* **即時反映機能**: 保存ボタンをクリックした瞬間に管理バーの表示が同期されます（手動リロード不要）。
* **サイト名の自動省略**: サイト名が長い場合に自動で15文字に省略（末尾「...」）し、バーの表示崩れを防ぎます。
* **GitHub自動更新対応**: GitHubリポジトリと連動し、管理画面からアップデート通知を受け取ることが可能です。
* **パフォーマンス最適化**: 軽量なフック処理と最小限のDBアクセスで設計されており、メモリ制限の厳しい環境でも軽快に動作します。

== Installation ==

1. プラグインフォルダを配置します。
   `wp-content/plugins/my-admin-bar-customizer/`

2. WordPress管理画面の「プラグイン」から有効化します。

3. 「設定 > 管理バー設定」から非表示にしたい項目を選択し、「変更を保存」をクリックしてください。

== Usage ==

プラグインを有効化すると、現在認識されている管理バーの項目がリストアップされます。

* **非表示設定**: 非表示にしたい項目のチェックボックスをオンにして保存してください。
* **項目の追加検知**: 新しいプラグインの項目がリストに出ない場合は、一度サイトのフロントページ（公開側）を表示してから設定画面をリロードしてください。
* **自動更新**: アップデートがある場合、WordPress標準の更新通知として表示されます。

== Settings ==

「設定 > 管理バー設定」より以下を設定可能です：

* **非表示にするメニューの選択**: 検知された親メニューの一覧から選択します。
* **検知済みリストをリセット**: DBに保存されたメニュー構造を初期化し、現在の環境で再スキャンします。

== Notes ==

* このプラグインは「非表示にする項目を選ぶ」方式のため、チェックを入れていない項目が勝手に消えることはありません。
* サイト名の省略ロジックは、管理バー上の表示のみを変更し、実際のサイト名設定には影響を与えません。
